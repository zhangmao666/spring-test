# 企业健康评估助手

## 触发条件
当用户询问企业评估相关问题，或提供企业运营数据需要进行健康度评估时触发此技能。常见提问方式如：
- "帮我评估一下这家企业的健康状况"
- "科技行业企业评估标准是什么"
- "给我生成一份企业评估报告"
- "这家企业的得分是多少"

## 执行步骤
1. 向用户确认两个必要参数：
   - 企业所属行业（如科技、制造业、服务业等）
   - 企业运营数据（JSON格式，包含references/企业评价指标.xlsx中列出的20项四级指标数据）
2. 执行评分脚本：
   ```bash
   node <技能目录>/scripts/evaluate.js {{industry}} '{{enterpriseData}}'
   ```
   详细接口规范见 references/新增企业评估标准接口.docx，指标权重说明见 references/企业评价指标.xlsx
3. 解析脚本输出的JSON结果
4. 整理评估结果并按照输出格式要求呈现

## 输出格式
以Markdown格式输出企业健康评估报告，包含以下内容：
1. **基本信息**：企业所属行业、评估日期
2. **综合评估结果**：总得分、健康等级（优秀/良好/合格/不合格）
3. **维度得分详情**：以表格形式展示各项指标的原始值、标准值、单项得分、加权得分
4. **改进建议**：针对得分较低的指标提出具体改进方向
