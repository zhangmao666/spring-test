# 天气查询技能

## 目标
通过调用 sojson 免费天气 API 获取城市真实天气数据。

## 操作步骤

1. 从用户问题中提取城市名称
2. 根据下方的城市编码表，找到对应的编码
3. 使用 ShellTools 执行脚本，传入城市编码（纯数字）：
   `cmd /c "<skills目录>/weather-query/scripts/get-weather.bat 101010100"`
4. 脚本返回 JSON 格式天气数据
5. 解析数据，用友好语言回复用户

## API 返回的关键字段
- `data.wendu`: 当前温度（摄氏度）
- `data.shidu`: 湿度
- `data.pm25`: PM2.5 指数
- `data.quality`: 空气质量等级
- `data.ganmao`: 感冒提示
- `data.forecast[0]`: 今日天气预报
  - `type`: 天气（晴/阴/雨/雪等）
  - `high`/`low`: 最高/最低温度
  - `fx`: 风向
  - `fl`: 风力等级

## 回复要求
- 展示温度、天气状况、湿度、空气质量
- 根据天气给出穿衣/出行建议
- 如果有感冒提示信息，也展示给用户
- 使用天气 emoji（🌤️ ☀️ 🌧️ ❄️ 🌡️ 💨）
